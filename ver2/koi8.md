Проблема с русской кодировкой в браузерном JS почти всегда сводится к одному из трёх пунктов: файл сохранён не в UTF‑8, нет правильного `<meta>`, или сервер отдаёт неверный `Content-Type`.

## Что нужно сделать прямо сейчас (по шагам)

### 1. Проверьте, что все файлы сохранены в UTF‑8 (без BOM)

Это самая частая причина: редактор сохраняет в Windows‑1251 или UTF‑8 с BOM, и браузер показывает «кракозябры».

- **VS Code**: в правом нижнем углу статус-бара нажмите на кодировку (обычно там написано «Windows 1251» или «UTF‑8 with BOM») → выберите «Save with Encoding» → **UTF‑8**.
- **Notepad++**: меню Encoding → выберите **Encode in UTF‑8** (не «Convert to UTF‑8‑BOM»).
- **Sublime Text / другие**: убедитесь, что кодировка файла — UTF‑8 без BOM.

---

### 2. Добавьте правильный meta‑тег в `index.html`

В `<head>` обязательно должна быть строка:

```html
<meta charset="utf-8">
```

Пример:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8">
    <title>SVG Viewer</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
...
```

Без этого браузер может угадывать кодировку и ошибаться.

---

### 3. Если открываете через GitHub Pages / локальный сервер — проверьте заголовок `Content-Type`

- **GitHub Pages**: отдаёт файлы с `Content-Type: text/html; charset=utf-8` автоматически, если файл в UTF‑8.
- **Локальный сервер** (например, `python -m http.server`, Live Server в VS Code): обычно тоже всё ок.
- **Открытие через `file://`**: тут бывает, что браузеры по‑разному интерпретируют кодировку. Лучше запускать через локальный сервер.

Если вы используете свой сервер (Node/Express и т. п.) — убедитесь, что для `.html` и `.js` явно указан `charset=utf-8`.

---

## Важные нюансы именно для вашего проекта

1. **В `config.js` русские строки (если будут)** — тоже должны быть в UTF‑8. Но у вас там сейчас только URL, они ASCII, проблем не вызывают.
2. **SVG‑файлы**: если внутри SVG есть текст на русском, сам SVG должен быть в UTF‑8 и иметь:
   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   ```
   в первой строке. Иначе текст внутри SVG будет отображаться некорректно независимо от HTML.
3. **Логирование**: в `app.js` нет проблем с кодировкой — `textContent` и шаблонные строки работают корректно, если сам файл в UTF‑8.

---

## Как быстро проверить, что всё исправлено

1. Откройте `index.html` в браузере.
2. Нажмите F12 → Console.
3. В логах должны нормально отображаться русские фразы из `UTILS.log(...)`.
4. В интерфейсе панели должны быть читаемые надписи: «filelist», «properties», «diagram», «log», а также сообщения вроде «Выберите файл в filelist».
